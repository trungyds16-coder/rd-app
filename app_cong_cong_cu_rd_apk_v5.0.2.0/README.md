# Cổng công cụ RD – Bản Android APK (v4.3.1)

## Cập nhật phiên bản 4.3.1:
- Duy trì chế độ Sáng/Tối và ngôn ngữ VI/EN xuyên suốt cả ở màn hình Đăng nhập lẫn bên trong app (có nút chuyển đổi trực tiếp trên màn hình đăng nhập).
- Sửa triệt để lỗi icon APK trắng trơn trên Android 8+ bằng cách cấu hình trực tiếp Adaptive Icons (`mipmap-anydpi-v26/ic_launcher.xml`, `drawable/ic_launcher_background.xml`, `values/ic_launcher_background.xml`) và dựng icon bình nón bo tròn mềm mại đồng bộ 100% với bản Web.
